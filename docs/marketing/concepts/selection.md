# Header selection

The first header used a small track-to-track arrow. Its compact format left little room to explain the review step, so `hero-original.svg` is kept here as the starting point.

`hero-light.svg` explored a spare layout on a pale background. The selected `hero-dark-selected.svg` gives the review mark more weight and stays legible against GitHub's light and dark themes. `docs/hero.svg` is an exact copy of the selected file and is the only header linked from the README.

The SVGs are editable and contain no release number. The wordmark, track lines, arrow, and check mark were drawn for this project.
